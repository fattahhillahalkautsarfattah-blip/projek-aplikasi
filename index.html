Panduan Aplikasi Alarm Web

⏱️ Aturan Auto-Stop 30 Menit (FR-07)

Setiap alarm yang berbunyi akan memutar audio secara loop dan mengaktifkan timer otomatis 30 menit. Jika Anda tidak mematikan alarm (misal tidak ada di ruangan), alarm akan otomatis berhenti sendiri tepat pada menit ke-30 dan statusnya dicatat sebagai "berhenti otomatis" di riwayat.

🎵 Nada MP3 Kustom (FR-04)

Anda dapat mengunggah file lagu atau nada MP3 sendiri hingga ukuran 10 MB per alarm. File disimpan secara aman di memori browser lokal (IndexedDB) dan tidak dikirim ke internet.

⚡ Tab Latar Belakang & Izin Notifikasi

Agar alarm berbunyi tanpa kendala, biarkan tab ini tetap terbuka di browser. Tekan tombol "Aktifkan Audio" dan izinkan notifikasi desktop agar peringatan tetap muncul walau Anda sedang membuka aplikasi lain.
